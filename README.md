# Palm and Pine

A restaurant website built with pure HTML, CSS, and JavaScript — no frameworks or libraries. Browse a multi-category menu, manage a cart across pages, and check out through a payment form.

## Pages

| Page | Description |
|------|-------------|
| `project.html` | Homepage with flip-card category previews |
| `about.html` | Restaurant story and mission |
| `starters.html` | Starters menu |
| `drinks.html` | Drinks menu |
| `indian.html` | Indian dishes menu |
| `international.html` | International dishes menu |
| `desserts.html` | Desserts menu |
| `sides.html` | Sides menu |
| `cartSummary.html` | Cart review with item breakdown and total |
| `payment.html` | Billing address and card payment form |
| `thanku.html` | Order confirmation page |
| `login&signup.html` | Login and sign-up page |

## Features

- Multi-page cart using `localStorage` — items persist as you navigate between menu sections
- `+` / `−` quantity controls on every menu item
- Dropdown navigation to jump between menu sections
- Payment form with validation (card number accepts both plain digits and dash-formatted input)
- Responsive footer with outlet locations, social links, and opening timings

## How to Run

No build step needed. Open `project.html` in any browser.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
